Why WebGPU

One million independent state updates belong beside the pixels, not in a JavaScript loop.

  1. CPU samples a serif M. mask once and uploads target coordinates.
  2. WGSL compute reads and writes one 32-byte particle struct.
  3. Dispatch uses 256 threads per workgroup with bounds checking.
  4. Curl-style flow, glyph attraction, ring attraction, and scroll agitation blend per frame.
  5. WGSL render expands each stored position into one small triangle.
  6. The HUD divides the actual GPU buffer byte size by the struct stride.
